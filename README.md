# hydro_tool

An interactive map viewer for NEREIDA's monthly seasonal hydrological
forecasts across the Ter and Tordera basins (Catalonia): streamflow, river
temperature, and Sau–Susqueda reservoir volume, gate temperature, and water
age (residence time).

Live at the repo's GitHub Pages URL (root `index.html`, no build step).

## What it shows

A split-screen Leaflet map: pick a station on the map, pick a
forecast month from the date selector (or click **Darrera previsió** to jump
to the latest), and the right-hand panel loads that station's density
forecast plots for the selected month.

Stations and their plots (defined in the `STATIONS` array in `index.html`):

- **Ter basin** — Ripoll, Roda de Ter (Sau inflow), Gola del Ter (river
  mouth): streamflow and river temperature.
- **Tordera basin** — equivalent upstream/middle/mouth stations.
- **Reservoirs** — Sau and Susqueda: system volume, and per-gate depth
  (three gates at Sau, four at Susqueda) gate temperature, water age, and
  time-to-peak transit.

Each plot is a tercile density chart: the forecast ensemble's distribution
at each lead month, shaded against the 1995–2025 climatology, with observed
value and skill markers where available.

## Repository layout

```
index.html                     The viewer (map + station data + plot loader)
density_plots/<year>-<month>/  One folder per forecast month (1995-01 onward),
                                containing every station's PNG density plots
seasonal/verification/         Skill-score reference tables (residence time,
                                pulse-tracer/time-to-peak), carried alongside
                                the plots for reference
```

`index.html` resolves each station's images as
`density_plots/<selected-month>/<file>` — adding a new month only requires a
new `density_plots/<year>-<month>/` folder with the same filenames as the
existing ones.

## Data source and updates

All content here is generated by the seasonal forecasting pipeline in
[`NEREIDACA/main`](https://github.com/NEREIDACA/main) (Copernicus SEAS5.1 →
GR4J hydrology + GLM/GLM+AED2 reservoir model, calibrated 1995–2025). This
repo has no logic of its own beyond the map/viewer — it is a publish target.

It is updated automatically by `main_operational.sh` in that pipeline on
each monthly run:

1. The new month's forecast is generated in
   `seasonal/forecast/<year>-<month>/` and its density plots in
   `tool/density_plots/<year>-<month>/`.
2. `tool/tercile_map_viewer.html` is copied here as `index.html`.
3. That month's non-SWI density plots are copied into
   `density_plots/<year>-<month>/`.
4. This repo is committed and pushed automatically.

No manual step is normally required; to publish a month out of band, mirror
those same two copy steps by hand.

## About NEREIDA

Built by Daniel Mercado-Bettín, Rafael Marcé and Jordi Pagès at the Centre d'Estudis
Avançats de Blanes (CEAB–CSIC). Applied here to Sau and Susqueda, the tandem
reservoirs on the River Ter that supply drinking water to the Barcelona
metropolitan area — a system pushed to record lows during the 2021–2024
Catalan drought. Both reservoirs are managed by the Agència Catalana de
l'Aigua (ACA); this work is part of the NEREIDA project, grant
RDI001/24/000044, funded by ACA under the R+D+I call ACC/1362/2024.
